🔴 Exercise 1 — Reflected XSS

The search bar above reflects the q parameter directly into the page without escaping (Jinja2 | safe filter). Any HTML or JavaScript is executed.

Payload
<script>alert('XSS from AcmeCorp')</script>
Attack URL
/?q=<script>alert('XSS from AcmeCorp')</script> ▶ Launch XSS ▶ HTML Injection
✔ Expected: browser alert fires / bold red text appears in the reflected output bar.
